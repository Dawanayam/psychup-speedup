# Origine

Speedup est une implémentation Psychup indépendante. Le README historique indique une inspiration fonctionnelle de SpeedUp 3.5, sans reprise de son code, de ses icônes ou de ses dépendances. L’extraction ne contient que les six fichiers du module Psychup, un manifeste autonome et un lanceur dédié. Aucun code tiers de l’ancienne extension n’est distribué ici. Les dépendances de développement conservent leurs propres licences.
