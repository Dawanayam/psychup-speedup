# Contribuer

Décrire le navigateur, le système, les étapes et le résultat attendu dans une issue. Ne pas joindre cookies, jetons ni exports privés. Avant PR : npm ci, npm test, npm run test:browser. Pour modifier les six sources partagées, coordonner le report Psychup puis régénérer les empreintes avec le script sync. Les tests synthétiques ne prouvent pas le fonctionnement d’un service distant. Aucune nouvelle permission ou dépendance sans expliquer son besoin.
