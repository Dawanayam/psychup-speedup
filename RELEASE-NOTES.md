# Psychup Speedup 0.1.0

Première extraction autonome de Speedup : soleil, planètes de vitesse et train, écran de réglage par onglet source. Code partagé avec Psychup et synchronisation explicite par empreintes.

Télécharger le ZIP, extraire dans un dossier permanent, charger ce dossier dans chrome://extensions en mode développeur. Aucun build nécessaire. Voir README et VALIDATION pour limites et tests.

Windows vérifié en Chrome for Testing ; même source prévue pour Chromium sous Linux, CI fournie. Interface française. Licence MIT. Pas de publication Chrome Web Store. Ne pas activer deux contrôleurs Speedup simultanément sur la même page.
