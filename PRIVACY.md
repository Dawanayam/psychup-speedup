# Confidentialité

Aucune collecte, télémétrie ou transmission par cette extension. La vitesse et la position du widget sont enregistrées dans chrome.storage.local. Le traitement porte sur les médias HTML des pages autorisées. YouTube/Crunchyroll sont autorisés pour le widget automatique ; les autres accès sont demandés explicitement. Les données du site restent soumises à sa propre politique. Aucun secret ni compte nécessaire. Le mode privé est désactivé.
